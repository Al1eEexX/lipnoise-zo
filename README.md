# lipnoise-zo

Безградиентная выпуклая оптимизация при липшицевом шуме в значениях функции: теория (черновик) и эксперименты для математического практикума.

## Результат в одной строке

Для выпуклой $M_f$-липшицевой задачи на множестве диаметра $D$ шум вида «$M$-липшицева функция + колебание не больше $\Delta_0$» допустим тогда и только тогда (с точностью до констант и логарифмов), когда

$$M \lesssim \varepsilon/D, \qquad \Delta_0 \lesssim \varepsilon^2/(\sqrt d\, M_f D),$$

причём амплитуда шума может быть любой. Липшицева часть допустима на уровне $\Theta(\varepsilon/D)$ без зависимости от размерности. Доказательства — в [`notes/lipschitz_noise.pdf`](notes/lipschitz_noise.pdf).

## Что здесь нового

Для функций с ограниченным гессианом точный порог $\Theta(\varepsilon/R)$ уже доказан в [arXiv:2610.05517](https://arxiv.org/abs/2610.05517). Для негладкого двухточечного случая в [arXiv:2202.06114](https://arxiv.org/abs/2202.06114) получено $\varepsilon/(D\sqrt d)$ с гипотезой, что это точно. Здесь показано, что и в негладком случае порог равен $\Theta(\varepsilon/D)$, то есть множитель $\sqrt d$ был артефактом анализа. Показано также, откуда $\sqrt d$ берётся: такое смещение возможно, только если шум знает текущее случайное направление метода. Добавлены скачки $\Delta_0$, зависящие от $x$, и эксперименты с реальным округлением. Вклад скромный: это сочетание известных приёмов, подробности — в разделе «Связь с литературой» черновика.

## Структура

| Путь | Что там |
|---|---|
| `lipzo/noise.py` | модели шума: ступенька (ограниченный шум), липшицева «рампа», инф-свёртка из леммы 1 |
| `lipzo/estimators.py` | двухточечная оценка, точная одномерная квадратура смещения по сфере |
| `lipzo/methods.py` | проекционный ZO-SGD на шаре, векторизованный по независимым запускам |
| `tests/test_theory.py` | численные проверки лемм, предложений и короткий прогон теоремы 1 (24 теста) |
| `experiments/e1_bias.py` | смещение в зависимости от $d$: ступенька $\sim\sqrt d$, липшицев шум $\le M$ |
| `experiments/e2_phase.py` | фазовый переход (слайд 29 доклада) в плоскости (амплитуда, наклон) |
| `experiments/e3_rounding.py` | реальное округление fp16/bf16/fp32 и стохастическое округление |
| `experiments/e4_theorems.py` | теорема 1 с её константами; порог липшицева шума не зависит от $d$, ограниченного — $\propto1/\sqrt d$ |
| `experiments/e5_dead_zone.py` | закон мёртвой зоны при округлении: порог $\gamma\propto\sqrt d$ |
| `docs/experiments.md` | подробные описания всех экспериментов: постановка, предсказание, числа, выводы |
| `results/` | графики (`.png`, `.pdf`) и сырые числа (`.json`) |
| `notes/` | черновик теории в LaTeX с полными доказательствами |

## Как воспроизвести

```bash
pip install -r requirements.txt
bash run_all.sh        # тесты + все эксперименты, около трёх минут на одном ядре
```

Все эксперименты детерминированы (фиксированные зёрна генератора).

## Основные численные результаты

- **E1.** Смещение от ступенчатого шума растёт как $\sqrt{2d/\pi}\,\Delta/\gamma$ (совпадает с формулой до $10^{-4}$); от липшицева шума ограничено наклоном $M$ при всех $d$ от 4 до 1024.
- **E2.** Предсказание «метод блокируется ⇔ смещение больше градиента задачи» совпадает с экспериментом в 97,6% клеток сетки 13×13; расхождения — у самой границы, где шум замедляет, но не останавливает метод.
- **E3.** Для реального округления оценка худшего случая пессимистична на 2–3 порядка; отказ при малом радиусе сглаживания вызван «мёртвой зоной» (разность округлённых значений равна нулю), порог у bf16 в 8 раз больше, чем у fp16.
- **E4.** Теорема 1 с её собственными константами выполняется с запасом примерно в 12 раз (ошибка не больше $0{,}083\varepsilon$ при $d$ до 40); порог липшицева шума одинаков при $d=5,20,80$, порог ограниченного — сдвигается как $1/\sqrt d$.
- **E5.** Порог мёртвой зоны $\gamma_{\mathrm{crit}}\approx0{,}2\sqrt d\,q/M_f$ при $d$ от 4 до 128 (наклон $0{,}49$ при предсказании $0{,}5$).

Подробности — в [`docs/experiments.md`](docs/experiments.md).
